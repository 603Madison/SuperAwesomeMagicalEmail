# SuperAwesomeMagicalEmail 0.2.1

- **Signing in through SuperAwesomeMagicalOrchestrator needs one tap fewer.** The phone app now
  knows the orchestrator app by its signing certificate, so it no longer shows your mail server's
  address and waits for a tap the first time. It also listens to nothing else that claims to be
  the orchestrator.
- Nothing changes on the server or in the Linux app beyond the version.
